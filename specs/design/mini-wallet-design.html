Propuesta de diseño · Web Challenge

Mini Wallet, con el lenguaje visual de Spin

Tokens extraídos del CSS en producción de spinbyoxxo.com.mx, un set pequeño de componentes y el flujo completo con todos sus estados: carga, vacío, error y los cinco resultados de la confirmación. Mobile-first, tema claro, interfaz en español (es-MX).

Login→ Home→ Nueva transferencia→ Confirmación / Comprobante

Fundamentos

Tokens de marca

El morado de Spin define estructura y navegación; el naranja OXXO se reserva para la acción principal de cada pantalla, igual que en su sitio. Los colores de estado son independientes de la marca para que un error nunca se confunda con un CTA.

Implementación

Cómo se traduce a código

Los tokens viven como variables CSS y en el @theme de Tailwind v4. Cada componente tiene su *.module.scss con BEM; Tailwind solo arma el layout de las páginas.

// src/components/ui/button/button.module.scss
.button { font-family: var(--font-display); border-radius: var(--radius-pill); }
.button__spinner { … }
.button--primary { background: var(--color-brand-orange); }
.button--secondary { box-shadow: inset 0 0 0 2px var(--color-brand-purple); }
.button--block { width: 100%; }

// uso: estilos de componente por BEM, layout de página con Tailwind
<Button variant="primary" isLoading block>Confirmar envío</Button>
<section className="flex flex-col gap-4 lg:grid lg:grid-cols-[1fr_320px]">

Accesibilidad

Contraste AA en todos los pares de texto, foco visible en lavanda, errores con aria-describedby, montos legibles por lector de pantalla y respeto a prefers-reduced-motion.

Copy

Todo el texto en archivos de mensajes de next-intl (es-MX). Mensajes de error que dicen qué pasó y qué hacer, sin culpar al usuario.

Datos sensibles

Cuentas siempre enmascaradas (•••• 5678). Opción de ocultar el saldo con el ícono de ojo en el Home.

Logo

En esta propuesta uso el SVG público del sitio de Spin. Lo reemplazo por los assets que me compartas, sin cambiar layout.
